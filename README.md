# FERRO DESIGN — Сайт студии дизайна интерьера

Официальный сайт дизайн-студии **FERRO DESIGN** (Екатеринбург / Нижний Тагил).

## Стек технологий
- **HTML5** (Семантическая верстка)
- **CSS3** (Кастомные свойства, Flexbox, Grid, стеклянный неоморфизм / glassmorphism)
- **JavaScript (ES6+)** (Интерактивные карты Яндекс, полноэкранный Lightbox, эффект 3D-наклона VanillaTilt, навигационный шпион скролла)
- **Шрифты**: Unbounded, Manrope, Inter

## Структура проекта
- `index.html` — Главная страница (Hero, Услуги, Портфолио, О студии, Интерактивная карта филиалов, Контакты)
- `projects.html` — Общий каталог всех реализованных проектов и концептов
- `project-*.html` — Детальные страницы кейсов (ЖК «Макаровский», «Нагорный», «Некрасова», апартаменты и загородные дома)
- `style.css` — Главная таблица стилей
- `script.js` — Логика интерактивных компонентов и анимаций
- `images/` — Каталог рендеров и графических материалов
